Autotile template — 4-bit edge set (16 tiles)

The engine reads tileset.png as a 4×4 grid. For each solid cell it computes mask = (N?1:0) | (E?2:0) | (S?4:0) | (W?8:0) (a bit is set when that neighbour is solid) and blits cell index = mask → col = mask & 3, row = mask >> 2. Paint each of the 16 slots below in its labeled role and it lands automatically.

Labeled layout (what to draw where)

Save the gray-box sheet as tileset.png next to three-beards.html to test the pipeline immediately, then replace each cell with real art at the same grid positions. Any square cell size works (32/64/128…); the engine scales cells to the 32px tile.
